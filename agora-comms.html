I. SYSTEM OVERVIEW

A. Technical Specifications

  • Frequency Range: 30-512 MHz continuous coverage
  • Power Output: 5W (High), 1W (Medium), 0.5W (Low)
  • Modulation: FM, AM, USB, LSB
  • Channel Capacity: 8 Zones × 16 Channels = 128 total
  • Encryption: NSA Type 1 certified
  • Battery Life: 12+ hours typical operation

B. Key Capabilities

  • Software-defined architecture (SCA compliant)
  • Simultaneous voice and data transmission
  • GPS-enabled position reporting
  • Ad-hoc networking (ANW2C waveform)
  • UHF SATCOM capability
  • SINCGARS interoperability

II. OPERATIONAL PROCEDURES

A. Power-On Sequence

  1. Ensure battery is properly installed and charged
  2. Attach antenna securely to top connector
  3. Turn VOLUME knob clockwise to power on
  4. Wait for self-test completion (approx. 30 seconds)
  5. Verify display shows operational status

B. Basic Communications Setup

  1. Zone Selection: Press ZONE, use ↑↓ to select A-H
  2. Channel Selection: Press CHAN, use ↑↓ to select 1-16
  3. Frequency Manual Entry:
    • Press FREQ SET
    • Enter frequency using numeric keypad
    • Press ENT to confirm
  4. Power Level: Press PWR, cycle through LOW/MED/HIGH
  5. Security Toggle: Press SEC to enable/disable encryption

C. Transmission Procedures

  1. Monitor channel for ongoing traffic (squelch open)
  2. Depress and hold PTT button
  3. Wait for TX indication on display
  4. Speak clearly into microphone (2-3 inches from mouth)
  5. Release PTT to receive
  6. Maintain communications discipline per SOI

III. ADVANCED FEATURES

A. Menu Navigation

Press MENU to access advanced settings:

  • RADIO SETUP: Power levels, scan lists, GPS settings
  • COMSEC: Encryption key management
  • NETWORK: ANW2C waveform configuration
  • UTILITIES: Test modes, diagnostics

B. Emergency Procedures

  1. Press and hold EMRG button for 3 seconds
  2. Radio automatically switches to emergency frequency
  3. GPS position transmitted with distress signal
  4. Emergency beacon activated
  5. To cancel: Press CLR twice within 10 seconds

C. GPS and Position Reporting

  • GPS automatically enabled on power-up
  • Position reports sent per network configuration
  • Manual position report: MENU → UTILITIES → GPS → SEND
  • Accuracy typically ±10 meters

IV. MAINTENANCE PROTOCOLS

A. Daily Operator Checks

  • Battery voltage check (>11.5V for full capacity)
  • Antenna connection security
  • Display clarity and backlight function
  • Audio quality on known good channel
  • GPS lock status verification

B. Troubleshooting

  • No Power: Check battery connection/charge level
  • Poor Audio: Verify antenna connection, adjust squelch
  • No GPS Lock: Ensure clear sky view, allow 2-5 minutes
  • Network Issues: Verify waveform configuration matches network
COMSEC REMINDER:
Proper key management and fill procedures are critical for secure communications. Never transmit classified information over unsecured channels. Maintain strict adherence to SOI and SSI requirements.

V. TACTICAL EMPLOYMENT

A. Mission Planning Considerations

  • Terrain analysis for line-of-sight communications

The Falcon III integrates seamlessly with:
